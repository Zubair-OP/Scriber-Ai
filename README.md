# 📌 Overview

Scriber AI is a modern full-stack AI Resume Builder designed to help job seekers build professional, ATS-friendly resumes with the power of Artificial Intelligence.

From writing compelling resume content to analyzing ATS compatibility and improving weak sections, Scriber AI streamlines the entire resume creation workflow in one place.

Whether you're a student, software engineer, freelancer, or experienced professional, Scriber AI helps you create resumes that stand out to both recruiters and Applicant Tracking Systems (ATS).

# 🚀 Getting Started

## Clone Repository

```bash
git clone https://github.com/Zubair-OP/Scriber-Ai.git
```

```bash
cd Scriber-Ai
```

## Install Dependencies

```bash
npm install
```

## Configure Environment Variables

Create a `.env.local` file.

```env
MONGODB_URI=

OPENAI_API_KEY=

NEXTAUTH_SECRET=

NEXTAUTH_URL=

STRIPE_PRICE_ID_PRO=

STRIPE_SECRET_KEY=

STRIPE_WEBHOOK_SECRE=
```

## Run Development Server

```bash
npm run dev
```
